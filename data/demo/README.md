# Demo Data Directory

This directory contains clearly labelled synthetic/demo data for software integration testing.

## Rules

1. All files here are DEMO DATA — not real environmental or landslide event data.
2. Never move demo data to `data/raw/`, `data/interim/`, or `data/processed/`.
3. All demo records in the database have `is_demo = TRUE`.
4. All demo API responses include `"demo": true`.
5. The UI shows a visible "DEMO DATA" banner when serving demo data.

## Contents

| File                          | Description                                   |
|-------------------------------|-----------------------------------------------|
| demo_zones.geojson            | 8 synthetic NER zones with representative terrain |
| demo_rainfall.csv             | 1 year of synthetic hourly rainfall (seasonal pattern) |
| demo_weather.csv              | 1 year of synthetic hourly weather data       |
| demo_soil_moisture.csv        | 1 year of synthetic daily soil moisture       |
| demo_landslide_events.csv     | 15 synthetic landslide events (is_demo=true)  |
| demo_roads.geojson            | Synthetic road network (3 NH, 5 SH segments)  |
| demo_villages.geojson         | 20 synthetic villages with population estimates |
| demo_infrastructure.geojson   | 10 synthetic infrastructure points            |

## Generation

Demo data is generated by `scripts/generate_demo_data.py`.
The script uses configurable seeds for reproducibility.
Do not edit demo files manually — regenerate via the script.

## Disclaimer

This data does not represent any real location, event, or measurement.
It is designed only to test software integration and demonstrate system functionality.
